# AI古菌官网（GitHub Pages）

> 站点仓库：gauss1777.github.io

该目录用于直接上传到 https://github.com/gauss1777/gauss1777.github.io，发布为主理人官网首页。

## 文件清单

- index.html：主页内容（中文）
- assets/style.css：页面样式
- assets/archaea-mark.svg：Logo 资源
- GITHUB_PROFILE_TEMPLATE.md：可直接复制为主账号 Profile README

## 发布方式（建议）

1. 将本目录内容推送到 gauss1777/gauss1777.github.io 根目录。
2. 在仓库设置中开启 GitHub Pages（Branch: master, /）。
3. 访问 https://gauss1777.github.io/ 进行预览。

## 后续维护建议

- 按季度同步一次研究地图与项目入口。
- 在主页中新增“最新内容”时间线或公告区块。
